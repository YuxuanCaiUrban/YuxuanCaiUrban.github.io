AI for Planning Online Textbook Teaching

Project update

The textbook source is now maintained in a private GitHub repository. The project is intended as an online learning resource that brings AI concepts into the practical work of reading evidence, examining places, and reasoning through planning decisions.

Current access

The reading site is not yet independently hosted. The current build can be viewed only while the local preview service is running on the computer that holds the source files.

The repository button opens the private source project for authorized collaborators; it is not a public textbook link. A stable reading link will be added here when a standalone public edition is available.

Access boundary: private source repository · local reading preview · no independent public textbook yet.
